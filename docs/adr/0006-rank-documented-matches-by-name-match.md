# Rank documented matches by how well their names match the search

Food search answers from two documented sources (ADR 0003), and a photo suggestion's pre-review estimate uses the first result. Results used to alternate with USDA FoodData Central first. FDC returns something for almost any query, so the first result was FDC's even for dishes FSANZ AUSNUT 2023 documents better, such as sushi and laksa, and the calibration pilot would mostly have measured FDC. Search now applies one test to both sources' results: a food whose name has every word of the query, matched the way AUSNUT's search matches words, ranks ahead of one whose name does not. Within each of those two groups the results still alternate with FDC first, so plain foods FDC covers well keep their place. AUSNUT's own search still needs every query word first. Only when that finds nothing does it retry with one word left out, so the photo query "salmon sushi roll" finds "Sushi, salmon" and queries that already match are unchanged. The photo analysis prompt is unchanged. A test list of about 20 realistic queries for the gap dishes in `docs/calibration/source-gaps.md`, each with the food it should find, checks both rules. A word swap such as "gyoza" to "dumpling" is added only for a miss that list shows. A name with every query word is not proof of the right food, and the person still chooses from the list. These changes land before the first calibration meal is run, so the pilot measures the ranking that ships (ADR 0002). AUSNUT's density rows, in grams per mL, stay unused. If the calibration report lists curries or noodle soups often among suggestions with no pre-review estimate, revisit this: convert volume units with density, then discard and re-run those meals before freezing the pass criteria.
