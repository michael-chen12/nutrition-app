# Keep each source's published nutrient values

When a documented source defines a nutrient differently from USDA FoodData Central, its adapter keeps the value the source publishes instead of converting it toward FDC's definition. The first case is FSANZ AUSNUT 2023 (ticket #13): its carbohydrate is available carbohydrate, which excludes dietary fibre, while FDC's is total carbohydrate by difference, which includes it. AUSNUT carbohydrates are stored as published (the "with sugar alcohols" column), so a matched AUSNUT food reads lower than its FDC twin by about its fibre content, and every stored value can be checked against the cited record. The only conversion is a change of unit: AUSNUT publishes energy in kJ only, so its "Energy with dietary fibre" is divided by 4.184 to give kcal. Where a source publishes kcal, that value is used. Each adapter documents the columns it reads. If calibration shows the carbohydrate skew matters, revisit this decision and add the source's dietary fibre to approximate total by difference.
