# Keep each source's published nutrient values

When a documented source defines a nutrient differently from USDA FoodData Central, its adapter keeps the value the source publishes instead of converting it toward FDC's definition. The first case is FSANZ AUSNUT 2023 (ticket #13). Its carbohydrate is available carbohydrate, which excludes dietary fibre. FDC's is total carbohydrate by difference, which includes it. The adapter stores AUSNUT carbohydrate as published, from the "with sugar alcohols" column. A matched AUSNUT food therefore reads lower than the same food from FDC by about its fibre content, and anyone can check every stored value against the cited record. The only conversion is a change of unit. AUSNUT publishes energy in kJ only, so the adapter divides its "Energy with dietary fibre" by 4.184 to give kcal. Where a source publishes kcal, the adapter uses that value. Each adapter documents the columns it reads. If calibration shows that the lower carbohydrate values matter, revisit this decision and add the source's dietary fibre to approximate total by difference.
